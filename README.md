# 🐾 Pet Adoption Cards

A simple and attractive **Pet Adoption Cards** webpage created using **HTML and CSS**. The project displays pet adoption cards featuring two adorable pets — **Tom the Dog 🐶** and **Cat 🐱**.

## 🌟 About the Project

This project is designed to showcase pet information in a simple card-based layout. Each card contains an image of the pet along with its name and adoption-related information.

The project currently includes **two pet cards**:

* 🐶 **Tom** — Dog
* 🐱 **Cat** — Cat

## ✨ Features

* 🐾 Two pet adoption cards
* 🐶 Dog card featuring Tom
* 🐱 Cat card featuring Cat
* 🖼️ Pet images displayed inside the cards
* 🎨 Simple and attractive card design
* 📱 Clean and easy-to-understand layout
* 💻 Built using basic web technologies

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the webpage
* **CSS3** – Used to style and design the pet cards
