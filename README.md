# 🐾 Pet Adoption Cards

### A Frontend Development & UI/UX Design Project by Deeksha M

A modern and responsive **Pet Adoption Cards** webpage designed and developed by **Deeksha M** using HTML5, CSS3, and JavaScript.

The project focuses on **frontend development, responsive web design, UI/UX design, visual design, reusable card-based components, and user-centered interface design** to create an attractive and easy-to-use pet adoption experience.

## 🌟 About the Project

**Pet Adoption Cards** is a frontend web project created to present adoptable pets through a clean, visually engaging card-based interface.

The project combines **web development and UI/UX design principles** to create a consistent visual experience for users exploring different pets.

Each pet card contains an image, pet name, and adoption-related information, presented using a reusable and consistent card structure.

The current version includes **seven pet profiles**:

- 🐶 **Tom**
- 🐱 **Jerry**
- 🐾 **Brownie**
- 🐾 **Luca**
- 🐾 **Luna**
- 🐾 **Milo**
- 🐾 **Padu**

- Glassmorphism-inspired cards
- Rounded corners
- Soft shadows
- Clean spacing
- Visual hierarchy
- Consistent typography
- Image-focused card layouts
- Subtle hover interactions
- Responsive design principles

The design aims to provide a **clean, elegant, approachable and visually engaging user experience**.
